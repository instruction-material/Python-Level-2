# Dice Roller starter

The starter rolls two six-sided dice and reports their total. Repeat this for 1000 pairs and report the relative frequency of each sum from 2 to 12. For a dry run, pairs 1/1, 1/6, 2/5, and 6/6 give sums 2, 7, 7, and 12. The counts for those sums are 1, 2, and 1. Explain why several different pairs make 7 while only 1/1 makes 2.
