# Song Generator 2 starter

Run the starter and check that quarter maps to 4. Build an input loop using the same dictionary rather than separate tests for each duration. Normalize case and spaces, then look up the chosen name. Reask after an unrecognized name.

Enter c4 with quarter, r with eighth, e4 with half, then q. Expect the pairs c4 and 4, r and 8, and e4 and 2. Allow up to six notes or rests. If the list stays empty, print a message and leave the audio output empty.
