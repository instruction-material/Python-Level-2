# Test Scores starter

Run the starter to see two score lists for the fictional names ari and bea. Complete a program that asks for the number of names and the number of tests. Trim names and use lowercase keys. A blank or repeated name should prompt for a replacement. Collect each test's scores for all names before moving to the next test. Scores are whole numbers from 0 through 100.

For names ari and bea, enter 80 and 100 for the first test, then 90 and 70 for the second. The two averages are both 85. With one name and zero tests, display No scores for that name.
