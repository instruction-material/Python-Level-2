# Coin Flipper starter

The starter calls flip_coin once and prints the returned label. Run it several times to see both heads and tails. Call it 1000 times in a loop, count each result once, and report both counts and percentages. For a small dry run with heads, tails, heads, tails, the two counts are both 2 and the percentages are both 50. A random run can differ from that exact split.
