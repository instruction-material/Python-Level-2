# Advanced Typewriter Monkeys starter

Run the starter with the supplied `valid_words.txt` beside `main.py`. It uses `xcatmint` to show the windows `xca` and `cat`, then finds `cat` on letter 4. The first two letters cannot form a three-letter window.

Generalize the window and word list to the selected length. At length 4 the sample finds `mint` on letter 8. Add a random mode that generates one letter at a time and stops after 20,000 letters if it finds no word. Report the number generated in either case.
