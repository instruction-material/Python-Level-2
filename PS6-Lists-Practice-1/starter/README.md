# Lists Practice starter

Run the starter and verify the eleven descending values from 10 through 0. Read a word and build a list of its characters in order. Generate the 100 squares of integers 1 through 100, then remove the ten whose values range from 2000 through 3000. Build a list from 1! through 25! by calling the factorial function. Return the sum and largest number using separate loops. For the list [-8, -3, -10], the sum is -21 and the maximum is -3. Guard the empty input to the maximum function.
