# Card Shuffler starter

The starter builds 52 numeric ranks. Each rank from 1 through 13 appears four times. Pick two indexes from 0 through 51 and swap the existing values. Put the swap in a loop and return the deck after the requested number of swaps. Compare 0, 10, 50, 100, and 500 swaps. Zero swaps keeps the sorted starting order. After every shuffle, there are still 52 cards and four of each rank.
