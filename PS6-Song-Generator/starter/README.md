# Song Generator starter

The starter builds a one-note sample. Add prompts for pitch and duration, then append one pair for each valid entry. Accept c4, d4, e4, f4, g4, a4, b4, c5, or r for a rest. Accept 1, 2, 4, and 8 as durations. Reask after an invalid entry, finish after six pairs, or accept q at the pitch prompt to finish earlier.

Enter C4 with duration 4, r with duration 8, and e4 with duration 2. Then enter q to render the three pairs in order. If no pairs were entered, print a message and skip rendering.
