# Number Games starter

The starter defines is_even and prints the even numbers from 1 through 50. Write is_odd, then derive it a second way by negating is_even. Add helpers for multiples of 7 and 14. The multiples of 14 in this range are 14, 28, and 42. A second implementation of that rule combines is_even and is_multiple7. Define is_prime using divisibility by smaller integers. Values below 2 are not prime. Check 0, 1, 2, and 49.
