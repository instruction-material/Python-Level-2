# Check-In 2 starter

1. The starter calls multiply with 15 and 22 and displays 330. Write a lottery-result function that accepts a win flag and an amount and returns a message. Compare a fixed loss with a fixed win of 75 before using random values.
2. Build a guest list by appending Ava, Ben, and Mina to an empty list. Remove Ava and print Ben and Mina on separate lines. Make a list from 1 through 20 and the list of ten even numbers from that range.
3. Create three player-to-jersey mappings. Add one entry, then add Curry with number 30 if that key is missing. Use fifteen distinct randomly selected keys from 0 through 1000 and store the length of each key's decimal representation as its value.
4. Compare garlic, onion, and salt with apple, cinnamon, and salt. Remove onion from the first recipe. Print the union, the intersection, and garlic's membership. Then make a set from banana and check that it has three different letters.
