# Functions Practice starter

Start with add and use the returned value in the output. Define subtract with two inputs, multiply with three, and average with two. Use loops for factorial of a nonnegative integer and an integer raised to a nonnegative whole-number power. For 2, 3, and 4, check sum 5, difference -1, product 24, and mean 2.5. The factorial of 4 is 24 and 2 to the third power is 8. Both 0 factorial and any supplied base raised to 0 return 1.
