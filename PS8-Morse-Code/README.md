# Morse Code

Encode text or decode dot-and-dash symbols. Separate letters by a space and words with a slash. The reference uses a dictionary in each direction and renders short signals as WAV audio.

Run `main.py` in the site IDE and play or download the audio. For a downloaded project, run `python3 main.py` beside `native_pysynth`. The prior example audio is retained in `original-morse-song.wav`.
