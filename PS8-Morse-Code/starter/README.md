# Morse Code starter

Run the starter to look up A and render a short note followed by a long note. Use the dictionary to encode uppercase or lowercase letters. Use a space between letter codes and a slash between words. Build a second dictionary from the first to decode in the opposite direction.

The words A I encode as `.- / ..`. When decoding, print A I. Report an unsupported letter or unrecognized token. Turn the codes into sound using a one-unit dot, three-unit dash, one-unit gap between symbols, three-unit gap between letters, and seven-unit gap between words.
