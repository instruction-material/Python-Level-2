# Check-In 1 starter

1. Run with dog and black. The starter prints the animal length, 3. Add the third color character (a), the combined guess, and an explicit conversion of 42 to text. For a color shorter than three letters, print a message and continue.
2. Print 0 through 10 with a for loop, the color characters in order, and 6, 9, 12, 15 with a stepped range. Print 0 through 15 with a while loop and every other animal character starting at index 1. For dog, that last sequence is o.
3. Compare the inputs with dog and black. Both matching gives Correct answer!, just one matching gives Almost there!, and neither gives Incorrect answer. Test dog/black, dog/tan, cat/black, and cat/red. A separate cat message can appear before the result. The optional loop prints 1 through 10 and terminates with a break when the counter reaches 11.
