# Check-In 1 practice starter

The first rule shifts all letters forward for even input length and backward for odd length. For the second rule, read another string and shift characters forward at even indexes and backward at odd indexes. Treat the indexes as zero-based. Wrap letters within their uppercase or lowercase alphabet and copy punctuation and spaces through unchanged. The length and index count include every entered character.

For Az!, the length rule gives Zy! and the index rule gives By!. For za, both length-rule letters move forward to ab, and the index rule produces az.
