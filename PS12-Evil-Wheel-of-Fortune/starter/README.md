# Evil Wheel of Fortune

Keep `dictionary.txt` beside `main.py`. Run the starter to count three-letter
candidates. Have the program choose a word length from three through eight. For each guess,
group the remaining words by where the letter appears, including the family
with no occurrence. Display a pattern from a largest family and keep only
that family's words. A guess that reveals no letter costs one turn. Type
`quit` to leave an unfinished game.
