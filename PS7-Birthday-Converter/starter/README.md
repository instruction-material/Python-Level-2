# Birthday Converter starter

Run the starter to see how 2 maps to February. Add a prompt for a sample date in mm/dd/yyyy. Reject inputs with missing parts, a month outside 1 through 12, or a day that does not exist in that month and year.

Expect 02/29/2024 to give February 29th, 2024. The same date in 2023 is invalid. Check 11th, 12th, and 13th before using the last digit for ordinary endings such as 21st, 22nd, and 23rd.
