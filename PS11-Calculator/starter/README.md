# Calculator starter

The starter reads two whole numbers and shows an addition expression. Write one helper per operation and send each menu choice to its helper. Ask for one operand for factorial and two for the other operations. Show the original expression and its result. Use q to exit.

Use whole numbers from -1000 through 1000. Factorials and exponents use inputs from 0 through 100. When the second number is zero, division and remainder should print a message and return to the operation menu. Try 12 / 3, 12 / 0, 0!, and 2 ^ 5. Expect 4.0, an explanation, 1, and 32.
