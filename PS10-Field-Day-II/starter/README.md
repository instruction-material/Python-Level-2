# Field Day II starter

The starter makes a working copy of a roster and picks the first red team member. Take each assigned name out of the working copy. Alternate Team Red and Team Blue. After each round, print the two team lists and the count still unassigned. Stop when every name is assigned. The original roster stays available.

Ten distinct names produce five on either team. With three names, Red gets two and Blue gets one. Test a one-person roster and an empty roster. The two teams should have no members in common.
