# Stock Trader starter

Histories are ordered from earliest to latest. Run the starter to see the most recent GOOGL value, 1122.00. Use one function to summarize each history. Skip calculations for an empty history, and display values to two decimal places.

A short history of 10, 20, and 30 has latest 30.00 and mean 20.00. A single value of 10 has latest and mean 10.00.
