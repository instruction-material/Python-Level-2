# Simple Twenty-One starter

Work with integer card values from 2 through 11. Deal two cards to each hand. Use h to draw, s to stay, or q to quit. A hand above 21 busts. The dealer draws below 17. Compare the totals when neither hand busts.

Use practice mode for a player hand of 10 and 7 and a dealer hand of 9 and 6. If the player stays, the dealer draws 3 and wins with 18. Replay the same mode to verify that neither hand carries over.
