# Favorite Foods starter

The starter compares two fixed sets. Add a function to collect five food names per group. Trim spaces and use lowercase so Pear and pear match. Ask again for a blank entry. A repeated food counts as one favorite in its set. Use an intersection for shared foods and two differences for the foods unique to either group.

With Group A {pear, apple, rice} and Group B {pear, rice, pasta}, shared foods are pear and rice. Only Group A has apple and only Group B has pasta.
