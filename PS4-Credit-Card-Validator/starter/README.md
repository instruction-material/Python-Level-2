# Credit Card Validator starter

Use short fictional digit strings. Run with 1479 to see the unweighted sum, 21. Read digits from right to left and leave the rightmost digit unchanged. Double alternate digits, reducing any doubled result above 9 by subtracting 9. Add the processed digits. The checksum passes when the total is divisible by 10. The processed total for 1479 is 20. Compare 1478 and the odd-length example 109. This is a checksum exercise for input errors.
