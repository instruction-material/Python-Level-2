# Debugging Functions

The broken starter first reports a syntax error. Repair the function declarations, then check the calls, argument counts, boolean returns, and scope of the guess count. The game picks one number from 1 through 100 and gives one response per guess. With a fixed target of 27 and guesses 20, 30, 27, the responses are too low, too high, and correct after three guesses. A correct first guess counts as one. The optional replay mode can call the completed game again with a newly chosen target.
